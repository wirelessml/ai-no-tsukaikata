# デモ動画の台本（約3分）

ナレーションは日本語。`scripts/record_demo.py` が、この文を音声にして、実際の画面操作の録画に重ねます。文言は `scripts/narration.py` が元です。

デプロイ後に、Cloud Run のURLを渡して録画し直します（本物のGeminiの応答になります）:

```bash
pip install -r requirements-dev.txt && playwright install ffmpeg
python scripts/record_demo.py https://<デプロイURL> submission/video/demo.mp4
```

## 撮影時の注意
- 画面下の字幕は、録画スクリプトが重ねます。
- YouTubeには「限定公開」ではなく、審査員が見られる設定（公開または限定公開のURL）で上げてください。提出は動画URLだけです。
- 現在の `submission/video/demo_DRAFT_mock.mp4` は、Geminiを使わない疑似応答モードで録画した下書きです。画面に「デモモード」の表示が出ています。提出には使わず、デプロイ後に録画し直してください。
