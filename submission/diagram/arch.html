AIの使い方を教えます　システム構成図

Cloud Run 上の FastAPI が、講師エージェントの4段階で Gemini（Vertex AI）を呼び出す。入力は保存しない。

学習者（スマホ / PC）

  • ブラウザで画面を開く
  • やりたいことを1行入力
  • 指示文を書く
  • 採点・実行・クイズを見る

入力しないもの

氏名・住所・電話番号など。入力欄で注意を出し、コードでも検出して止める。

Google Cloud（asia-northeast1 ほか）
Cloud Run：FastAPI コンテナ（max-instances 2 / 512Mi）

静的画面

HTML / CSS / JS
大きめの文字・スマホ対応
判断ログの表示

入力ガード・制限

  • 個人情報らしき文字列
  • 指示の上書きを狙う文
  • 文字数の上限
  • IPごとのレート制限
  • 1日の呼び出し上限
講師エージェント（app/agent.py）
1 計画可否・リスク・スキル選定
2 採点スキル別に◎△×
3 実行結果＋確認点
4 クイズ弱点を優先

コードによる制御

  • スキルは固定カタログのIDだけ
  • 出力はJSONスキーマで受け取り検証
  • 不正ならフォールバック（既定スキル・固定クイズ）

出力の安全策

  • 個人情報らしき文字列を伏せる
  • 医療・法律・お金は注意書きを追加
  • DB なし・入力は保存しない

Vertex AI（Gemini）

  • gemini-3.5-flash
  • Google Gen AI SDK
    （vertexai=True）
  • 構造化出力（JSON）
  • 認証は ADC のみ（キー不要）

IAM

実行用サービスアカウントに
roles/aiplatform.user のみ付与

Cloud Logging

構造化ログ。ステップ名・所要時間・トークン数のみ。本文は出さない
